# rib-vs-thickness — reproducible package

Equal-mass 200 x 100 mm 6061-T6 lid: a monolithic 4.0 mm plate against a 2.5 mm
skin stiffened by a 10 x 15 mm rib, both at 80,000 mm3 (216 g). Abaqus/Standard
2023, C3D8I linear static, quarter models.

## Files

| File | Role |
|---|---|
| `gen_decks.py` | parametric all-hex C3D8I deck generator (2-D section swept along y); also holds the case matrix and the geometry constants |
| `run_jobs.py` | writes each deck, runs `abaqus`, then calls `extract.py` through Abaqus Python |
| `extract.py` | odbAccess reader: nodal `U`, element-nodal `S` averaged onto nodes, external quad faces, mesh volume, reaction sum |
| `postprocess.py` | builds `results/cases.json`, `measurements.json` and evaluates the pass gates (`results/gates.json`) |
| `verify.py` | closed-form references and the 3-row check table (`--measure`); no solver output in the file |
| `render.py` | `fig1.png`, `fig2.png`, `video.mp4` — a numpy/Pillow software rasteriser, no pyvista/cv2/ffmpeg binary needed |

## Requirements

- Abaqus/Standard 2023 on `PATH` as `abq2023`, or set `ABAQUS_CMD` to the solver
  command (e.g. `export ABAQUS_CMD=/path/to/abq2023`).
- Python 3.9+ for `gen_decks.py`, `postprocess.py`, `verify.py`;
  `numpy` for `gen_decks.py`.
- `render.py` needs `numpy`, `matplotlib`, `Pillow`, `imageio`, `imageio-ffmpeg`.

## Run order

```bash
python code/gen_decks.py --list          # case matrix
python code/run_jobs.py --cpus 8         # 19 decks -> solve -> extract
python code/postprocess.py               # -> results/cases.json + gates.json
python code/verify.py --measure          # -> results/verify.json (frozen tolerances)
python code/render.py all                # -> fig1.png, fig2.png, video.mp4
```

`render.py` reads only `results/nodes_<CASE>.csv`, `results/faces_<CASE>.csv`,
`results/cases.json`, `results/verify.json` and `results/gates.json`; the large
raw CSVs are not shipped in the repository, they are regenerated by
`run_jobs.py` + `extract.py` from the solver output.

## What is quoted and what is not

- `w_center` at the plate centre, `U3` on the loaded surface, is mesh-converged
  on both headline variants (C vs B: 0.20% flat, 0.34% ribbed).
- The rib tip stress (`S22` at `z = t_s + H`) is converged on R15 (B to C
  0.1%). Ribbed skin peak `S11` is **not** converged (50.3 MPa on B, 56.6 MPa
  on C) because the 90-degree rib root is a stress singularity, so it is
  reported as mesh-dependent and never quoted. Only the 3 mm fillet variant
  carries a quoted root stress (B to C 3.03%, limit 5%).
- The quarter model is mirrored to the full lid in the figures. The 2.5 mm mesh
  is drawn with faint quad edges; nothing is smoothed, and every field value is
  a nodal average from the solver.
